## gest3015-miller-indices

#Repository Description:
- This repository explains what are miller indices in the context of 3D systems and Science.
-  Miller indices are a simple three-number code used by scientists to describe the exact angle of a flat slice or face inside a crystal. You can think of them as a 3D address system for the repeating building blocks of solid materials like diamonds, salt, or metals


#What is in Repository?
- There is currently a Single-file academic poster explaining Miller Indices (hkl), intercepts, and crystallographic planes.
